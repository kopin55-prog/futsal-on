# 묶음 테스트 01 (kopn 휴대폰·에뮬레이터 확인용)

작성 2026-11-05 lead. 스프린트 01 구현 1~4단계 결과(4단계 항목은 builder 추가). 확인하면서 이상한 점·바꿀 문구를 이 파일 아래 "메모"에 적거나 lead에게 말하면 된다.

## 실행 방법
1. `app` 폴더에서 `dart run tool/make_dev_config.dart` (`.env.local`에서 앱용 값만 옮김)
2. 휴대폰 연결(USB 디버깅) 또는 에뮬레이터 실행 후 `flutter run --dart-define-from-file=config/dev.json`
3. 카카오 디벨로퍼스 OpenID Connect 켜짐, 구글 안드로이드 OAuth 클라이언트(디버그 SHA-1) 등록이 되어 있어야 로그인됨
4. 두 사람 역할 테스트(가입 신청·승인 등)는 계정 2개(예: 카카오 1개 + 다른 이메일 구글 1개)

## 1. 로그인·가입
- [ ] 카카오 로그인 → 동의 화면 → 프로필 만들기 → "팀 만들기 / 팀 찾기" 홈
- [ ] 동의: 부상 정보 처음 해제, "전체 동의" 누르면 부상까지 체크, 필수 하나 빼면 "다음" 꺼짐
- [ ] 로그아웃 후 카카오 재로그인 → 동의 없이 바로 홈 (같은 계정)
- [ ] 구글도 같은 순서, 로그아웃 후 재로그인도 성공
- [ ] **같은 이메일**: 카카오와 구글을 같은 이메일로 차례로 로그인 → 두 번째는 바로 홈 (Supabase 대시보드 Users에서 그 사용자 identities 2개)
- [ ] **카카오 이메일 미인증**(가장 중요): 이메일 인증 안 된 카카오 계정(또는 이메일 제공 거부)으로 로그인 → 실패 문구인지, 새 계정 동의 화면인지 기록. 대시보드 Users에 새 사용자·email 칸 확인

## 2. 프로필
- [ ] 포지션 4번째는 막히고 "최대 3개까지 고를 수 있어요"
- [ ] 전문 골키퍼 체크 → 골키퍼 자동 선택·잠김, 체크 풀어도 골키퍼 남음
- [ ] 프로필 수정: 이름·소개·포지션 한 번에 저장 (포지션이 틀리면 이름도 안 바뀜)

## 3. 팀 만들기·전환
- [ ] 이름만으로 생성, 로고 글자 비우면 앞 두 글자
- [ ] 정기 운동일 22:00~00:30 저장, "다음날" 표시, 시작=종료는 거절
- [ ] 두 번째 팀 만든 뒤 앱 재실행 → 마지막 본 팀, 팀 이름 눌러 전환
- [ ] (4단계) 팀 만들기에서 로고 사진 고르기 → 정사각형 자르기 화면 → 미리보기에 사진 → 만들기 후 팀 화면 머리·팀 전환 목록에 사진 로고
- [ ] (4단계) 10MB 넘는 사진 / GIF·HEIC 등 JPG·PNG 아닌 사진은 안내 문구만, 자르기 취소하면 아무 변화 없음
- [ ] (4단계) 위치 정보가 있는 휴대폰 사진(GPS 켜고 찍은 사진)을 로고로 저장 → Supabase 대시보드 Storage > team-logos 에서 그 파일을 내려받아 사진 정보(EXIF)에 위치가 없는지, 512×512 PNG 인지 확인
- [ ] (4단계) 지정 풋살장: "정하지 않음" 누르기 → 구장 검색. **장소 검색 서버 함수 배포 전**에는 검색하면 "구장 검색은 준비 중이에요" 안내, "찾는 구장이 없으면 직접 입력"으로 이름·주소 저장 → 팀 찾기 결과에 구장 이름
- [ ] (4단계, place-search 배포 후) "강남 풋살" 검색 → 목록(이름·주소·분류) → 고르면 칸에 표시, 15개 넘으면 "더 보기". 저장 후 대시보드 teams 표에 venue_lat·venue_lng·venue_map_provider=kakao·venue_map_place_id

## 4. 초대·가입
- [ ] 관리 탭 초대 코드 발급·복사 → 다른 계정이 팀 찾기에 붙여넣어 신청 → 승인·거절
- [ ] 식별코드 소문자 입력도 찾음, 모집 마감 팀은 "모집 마감"·신청 버튼 없음 (초대 코드로는 가능)
- [ ] "이미 소속된 팀이에요", "이미 신청했어요", 보낸 신청 취소
- [ ] 이름 검색 1자면 안내, 2자 이상 결과

## 5. 팀원·역할
- [ ] 팀원 목록 역할 배지·자기소개. 일반 팀원에게 남의 포지션 안 보임, 팀장·운영진에게 보임
- [ ] 운영진 지정(3번째 거절)·해제, 위임(나는 운영진이 되고 메뉴 바뀜), 내보내기
- [ ] 팀원 자진 탈퇴 → 최근 본 다른 팀, 없으면 홈. 팀장은 탈퇴 안내만
- [ ] 해체: 이름 정확히 쳐야 버튼 켜짐("코코 fc"처럼 대소문자·공백 달라도 됨). 해체된 팀 코드 입력 시 "가입할 수 없는 팀이에요"

## 6. 관리 탭 팀 설정
- [ ] 팀장·운영진에게 "팀 설정" 메뉴 4개, 팀원은 관리 탭 없음
- [ ] 팀 정보 수정: 이름 변경 시 로고 미리보기 따라감. 직접 바꾼 로고 글자는 유지, 기본값으로 되돌리면 다시 따라감. 운영진은 로고 글자 칸 없음
- [ ] 모집 끄기 → 팀 찾기에 "모집 마감"
- [ ] (4단계) 팀 정보 수정: 로고 사진 바꾸기 → 저장 → 새 사진. 대시보드 Storage team-logos 의 그 팀 폴더에 파일 1개만 남음(이전 파일 삭제)
- [ ] (4단계) 로고 사진 지우기 → 저장 → 글자 로고. 팀 폴더 비어 있음
- [ ] (4단계) 운영진 계정도 로고 사진 바꾸기·지우기 가능. 일반 팀원 계정은 관리 탭이 없음
- [ ] (4단계) 다른 팀 계정(팀 밖 사람)이 팀 찾기·초대 코드 확인에서 그 팀의 사진 로고가 보임
- [ ] (4단계) 사진 로고가 있는 팀을 해체 → 대시보드 Storage 에서 그 팀 폴더 파일이 지워짐
- [ ] (4단계) 지정 풋살장 바꾸기·X 눌러 지우기 → 저장 → 다시 열면 그대로
- [ ] 경기 설정: 정원 없음 ↔ 정원, 0명·101명 막힘, 마감이 자동 생성보다 앞서면 저장 버튼 꺼짐
- [ ] 실력 등급: 운영진 화면에서 설정·유지, 팀원 계정으로는 볼 수 없음
- [ ] 그룹 A·B 켠 상태에서 라이벌 A·B 켜기 막힘 + 이유. 간접 모순(그룹 A·B, B·C → 라이벌 A·C)도 막힘. 삭제 확인창

## 7. 회원 탈퇴
- [ ] 확인 화면 문구 (실제 탈퇴는 서버 기능 배포 후, Q-068)

## 8. 문구
- [ ] 임시 문구 전체 훑어보고 바꿀 것 메모 (Q-067 0번). 4단계 새 임시 문구: 로고 사진 칸·오류 안내, 구장 검색 화면·직접 입력 창, iOS 사진 접근 권한 안내("팀 로고 사진을 고르려면…")

## 9. 디자인 (4단계, kopn "간결하고 깔끔하게")
- [ ] 화면마다 좌우 여백·버튼 높이·입력칸 모양·묶음 제목이 같은지 (밝은 모드·어두운 모드 둘 다)
- [ ] 소속 팀 없음·가입 신청 없음·그룹·라이벌 없음·구장 검색 결과 없음 화면에 아이콘과 안내
