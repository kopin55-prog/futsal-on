# 묶음 테스트 02 (kopn 휴대폰 확인용) — 초안

작성 2026-11-09 builder (lead 검토 전 초안). 스프린트 02 1~4단계 결과. 5단계(푸시)는 Firebase 준비 후 따로 추가한다.
확인하면서 이상한 점·바꿀 문구를 아래 "메모"에 적거나 lead에게 말하면 된다. 화면 문구는 모두 임시(Q-067 0번)라 고칠 문구를 알려주면 된다.

## 실행 방법
1. 묶음 테스트 01과 같다 (`app` 폴더에서 `dart run tool/make_dev_config.dart` → `flutter run --dart-define-from-file=config/dev.json`).
2. **계정 3개**가 있으면 좋다: 팀장 A, 운영진 B, 팀원 C (카카오 1 + 구글 2 등). 휴대폰 1대면 로그아웃·로그인으로 바꿔 가며 확인.
3. 서버 예약 작업(자동 생성·미투표 알림·참여율·정리)은 개발 DB에서 **매분** 돌아간다. 시각을 기다려야 하는 항목은 "가까운 시각"으로 설정을 바꿔 확인한다.
4. 푸시는 아직 없다(5단계). 알림은 앱 위쪽 **종 모양 → 알림함**에서 확인한다.

## 1. 정기 운동·자동 생성 (1단계, Q-073 1·8번)
- [ ] 팀 만들기·팀 정보 수정: 요일 고르고 **시작 시각을 고르면 종료가 시작 2시간 뒤로 자동으로 채워짐**, 종료는 바꿀 수 있음
- [ ] 종료를 지우면 "종료 시각도 골라주세요" 안내, 저장 안 됨 (요일만 정하는 것은 가능)
- [ ] 22:00 시작 → 종료 00:00(다음날) 자동, 00:30으로 바꾸면 "다음날" 표시
- [ ] 정기 운동을 **3일 뒤 요일**로 정함(기본 설정: 6일 전 09:00 생성, 2시간 전 마감) → 1분 안에 일정 탭에 그 일정이 생김, 팀원 전원(바꾼 사람 포함) 알림함에 "경기가 열렸어요!"
- [ ] 같은 정기 운동으로 다시 저장해도 일정이 두 개가 되지 않음
- [ ] **같은 시각 직접 추가**: 다른 팀(또는 운동일 없는 팀)에서 운영진이 "다음 주 그 요일 같은 시각" 일정을 먼저 직접 추가 → 그 요일·시각으로 정기 운동을 정해도 자동 일정이 하나 더 생기지 않음
- [ ] 위 직접 추가 일정을 취소하면(마감 전이면) 1분 안에 자동 일정이 생김
- [ ] 경기 설정에서 정원·마감을 바꿔도 이미 생긴 일정의 정원·마감은 그대로

## 2. 일정 목록·상세 (4단계 4-1)
- [ ] 팀 화면 첫 탭이 "일정". 다가오는 일정만(끝난 일정 없음), 시작 순
- [ ] 취소된 일정은 줄이 그어지고 "취소됨" 표시
- [ ] 아래로 당기면 새로고침
- [ ] 상세: 일시("11월 12일(수) 10:00 ~ 12:00", 자정 넘기면 "다음날"), 장소(없으면 "장소 미정"), 정원("정원 없음 (모두 참석)" 또는 "정원 N명" + 참석 인원), 마감("…까지 투표")
- [ ] 내 상태: 처음 "미투표" → "참석할게요" → "참석" → "이번엔 불참" → "불참"
- [ ] 명단 4개(참석·대기·불참·미투표)가 팀원 누구에게나 보임
- [ ] **명단 순서 (Q-073 7번)**: 참석·불참은 마지막으로 바꾼 순(불참 → 참석으로 바꾸면 참석 맨 뒤), 대기는 "1. 2. …" 순번, 미투표는 이름 가나다순
- [ ] 마감 시각이 지나면 버튼이 꺼지고 "투표가 마감됐어요" (휴대폰 시계를 바꿔도 서버가 거절)
- [ ] 취소된 일정 상세: 위에 "취소됨" + "사유: …"(사유가 있을 때), 투표 버튼 없음

## 3. 정원·대기 (2단계 + 경기 설정 화면)
- [ ] 경기 설정: "대기 사용" 스위치 꺼짐 = 정원 없음(모두 참석). 켜고 "참석 인원"에 2 입력 → "2명까지 참석, 3번째부터 대기" 안내 → 저장
- [ ] 그 뒤 만든 일정에서 3명째가 참석 누르면 "대기 1번"
- [ ] 참석자 한 명이 불참으로 바꾸면 대기 1번이 자동으로 참석 + 그 사람 알림함에 "자리가 났어요!", 참석 명단 맨 뒤에 들어감
- [ ] 대기 사용을 끄면 다음 일정부터 모두 참석 (이미 만든 일정은 그대로)

## 4. 운영진: 일정 추가·취소 (4단계 4-2)
- [ ] 팀원 계정에는 "일정 추가", "일정 취소", "게스트 추가"/삭제 버튼이 없음
- [ ] 일정 추가: 시작 날짜·시각, 종료 날짜·시각, 장소(선택, 검색 또는 직접 입력). 마감·미투표 알림 칸에 **팀 경기 설정 값이 먼저 채워져 있고** 이 일정만 바꿀 수 있음. 정원 칸 없음
- [ ] 지난 시각 → "이미 지난 시각이에요", 종료가 시작보다 이르면 안내(자정 넘기면 종료 날짜를 다음날로), 24시간 넘으면 안내
- [ ] 1시간 뒤 "번개" 일정(마감 2시간 전 설정) → 추가되고 경기 시작 전까지 투표 가능
- [ ] 추가한 운영진 본인을 뺀 팀원 알림함에 일정 생성 알림
- [ ] 일정 취소: 확인 창, 사유(선택) 20자까지만 입력됨, 비워도 취소 → 상세에 "취소됨"(+사유), 목록에도 "취소됨"
- [ ] 취소 알림은 그 일정에 투표한 사람에게만(취소한 본인 제외), 사유 포함
- [ ] 경기 시작 뒤에는 취소 버튼이 없음

## 5. 게스트 (Q-073 2·3번)
- [ ] 게스트 추가: 이름 비우고 추가 → "게스트1", 다시 비우고 → "게스트2"
- [ ] 이름 뒤에 작은 색 상자 "게스트"가 붙음 (팀원 화면에서도)
- [ ] "게스트1"을 지워도 "게스트2"는 그대로, 다음에 비우고 추가하면 "게스트3"
- [ ] 같은 이름(직접 적은 이름끼리, 또는 "게스트2" 같은 이름)은 "이 일정에 같은 이름의 게스트가 있어요"
- [ ] 이름 9자는 막힘, 포지션 4번째는 선택 안 되고 "최대 3개까지" 안내
- [ ] 12명이 되면 추가 버튼 꺼짐
- [ ] 운영진은 게스트 이름 아래 포지션·대략 실력이 보이고, 팀원은 이름만 보임
- [ ] 경기 시작 뒤·취소된 일정에서는 추가·삭제 버튼 없음
- [ ] 게스트를 추가·삭제해도 알림이 오지 않음

## 6. 알림함 (4단계 4-3)
- [ ] 위쪽 종 모양에 안 읽은 개수(두 팀에 소속돼 있으면 **두 팀 합계**)
- [ ] 알림함: 모든 팀 알림이 한곳, 항목마다 팀 이름, 최신순, "방금 / n분 전 / n시간 전 / 날짜"
- [ ] "모두 읽음" → 종 모양 숫자가 사라짐. 개별 삭제·안 읽음 되돌리기는 없음
- [ ] 일정 알림을 누르면 읽음 + 그 일정 상세로 이동. **취소된 일정 알림도 상세로 가서 "취소됨 + 사유"** (Q-073 4번)
- [ ] 가입 신청 알림(운영진)을 누르면 그 팀의 관리 탭으로
- [ ] 떠난 팀(팀 탈퇴·내보내짐·해체)의 알림은 남아 있고, 누르면 읽음만 되고 이동하지 않음
- [ ] 소속 팀이 없는 화면(팀 만들기/찾기 홈)에도 종 모양이 있음 (내보내짐·해체 알림 확인용)
- [ ] 숫자는 화면을 열 때·알림함에서 돌아올 때·팀을 다시 불러올 때 갱신 (앱을 켜 둔 채 새 알림 즉시 표시는 5단계)

## 7. 알림 문구·받는 사람 (3단계, Q-073 6·11번)
- [ ] 제목은 팀 이름, 본문은 Q-073 11번 승인 문구와 같음
- [ ] **내보내기**: 팀장이 팀원 C를 내보냄 → C 알림함 "팀에서 내보내졌어요. 그동안 함께 뛰어 주셔서 고마워요.", 운영진 B 알림함 "C이름님이 팀에서 내보내졌어요."(문구 초안, 확인 필요), 내보낸 팀장·다른 팀원에게는 없음
- [ ] 팀 탈퇴 → 팀장·운영진에게 "○○님이 팀을 떠났어요."
- [ ] 가입 신청 → 팀장·운영진, 승인·거절 → 신청자, 승인으로 합류 → 다른 팀원 알림함에 "새로 합류했어요!"
- [ ] 운영진 지정·해제, 팀장 위임 → 본인
- [ ] 팀 해체 → 팀원 전원(해체한 팀장 제외), 대기 중 신청자에게 "팀이 해체되었어요…"
- [ ] 회원 탈퇴 → 소속 팀 팀장·운영진에게 "○○님이 회원 탈퇴로 팀을 떠났어요."
- [ ] 미투표 알림: 알림 시각(예: 마감 2시간 전)에 아직 투표 안 한 팀원에게만 1회, 조용한 시간(00~08시)이어도 그 시각에
