# 동의 문구

상태: **부상 정보 동의 문구 kopn 확인 (2026-11-05, Q-057)**. 개인정보 처리방침·이용약관 본문은 출시 전 별도 작성.

## 가입 단계 (로그인 직후, 프로필 만들기 전)

### [필수] 만 14세 이상입니다
만 14세 미만은 풋살ON에 가입할 수 없어요.

### [필수] 이용약관 동의
(이용약관 보기)

### [필수] 개인정보 수집·이용 동의
(개인정보 처리방침 보기)

### [선택] 부상 정보 수집·이용 동의
부상을 기록하려면 동의가 필요해요. 동의하지 않아도 풋살ON을 이용할 수 있고, 부상 기록 기능만 쓸 수 없어요.

| 항목 | 내용 |
| --- | --- |
| 수집 항목 | 부상 여부, 예상 회복 기간, 부상 메모(20자 이내) |
| 이용 목적 | 소속 팀의 부상 인원 표시, 팀 운영 기록과 운영진용 팀 리포트 제공 |
| 공개 범위 | 내가 소속된 팀의 팀원 (팀 리포트는 팀장·운영진) |
| 보유 기간 | 동의 철회 또는 회원 탈퇴 시까지 (철회·탈퇴 즉시 삭제) |
| 거부 권리 | 동의하지 않을 수 있으며, 이 경우 부상 기록 기능만 이용할 수 없어요 |

동의는 프로필 설정에서 언제든 철회할 수 있어요. 철회하면 부상 기록이 바로 삭제돼요.

## 참고
- 부상 정보는 건강 정보(민감정보)로 볼 수 있어 다른 동의와 **분리해서** 받고, 항목·목적·보유 기간·거부 권리를 모두 적었다 (lead는 법률 전문가가 아님. 출시 전 처리방침 작성 때 함께 검토 권장)
- 2차 팀 리포트에 부상 기록을 쓰는 것까지 이 문구 하나로 포함 (Q-057)
