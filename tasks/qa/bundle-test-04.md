# 묶음 테스트 04 (kopn 휴대폰 확인용) — 초안

작성 2026-11-10 qa. 스프린트 04 1~6단계 결과(부상, 내 기록, 홈, 일정 탭, 팀원·관리 탭, 포지션 올라운더, 그룹·라이벌 검색). 7단계(iOS)는 해당 작업이 끝난 뒤 따로 추가한다.
확인하면서 이상한 점·바꿀 문구를 아래 "메모"에 적거나 lead에게 말하면 된다. 화면 문구는 대부분 임시(Q-067 0번)라 고칠 문구를 알려주면 된다.
표시: **[계정 2개]** = 계정 2개 이상 필요, **[계정 3개]** = 3개 이상 필요, **[실제 확인]** = 컴퓨터 테스트로는 확인이 안 되고 휴대폰 실제 로그인에서만 확인되는 것.

## 실행 방법
1. 04 마지막 커밋 이후 새로 만든 설치 파일(APK) 또는 USB `flutter run`. 개발 DB에는 0066까지 적용돼 있어야 한다(lead 확인).
2. **계정 3개**가 있으면 좋다: 팀장 A, 팀원 B, 팀원 C. 이 중 **부상 동의한 계정 1개(B)**와 **동의 안 한 계정 1개(C)**가 필요하다. (가입할 때 부상 정보 동의를 고르거나, 나중에 부상 등록 화면에서 동의하면 된다.) 휴대폰 1대면 로그아웃·로그인으로 바꿔 가며 확인.
3. 팀을 하나 더 만들어 B가 두 팀에 속하면 "두 팀" 항목도 확인할 수 있다 **[계정 2개]**.
4. **복귀 확인 알림 푸시**(7절)는 lead가 `supabase/scripts/setup_push.ps1`(notifier 배포)을 다시 실행한 뒤에만 휴대폰에 온다. 그 전에는 알림함(종 모양)에서만 확인한다.
5. 일정은 팀 설정의 "경기 설정"에서 정기 운동일을 바꾸거나 일정 탭에서 직접 추가해서 만든다. 시간이 걸리는 항목은 "가까운 시각"으로 일정을 만들어 확인.

## 1. 앱을 열었을 때 — 탭과 홈 (4-7, 6-3)
- [ ] 앱을 열면 **홈**이 첫 화면. 아래 탭 순서가 홈·일정·팀원·관리·내 기록 (팀원 계정에는 "관리" 탭이 없음)
- [ ] 위쪽 바에 팀 이름이 한 번만 보이고, 홈 맨 위에는 "팀원 N명"만 있음. 누르면 팀원 탭으로 감
- [ ] 팀원 수에 팀장·운영진이 들어 있고, 팀을 떠난 사람은 빠져 있음
- [ ] 밝은 모드·어두운 모드 둘 다 글자가 읽힘 (휴대폰 설정에서 바꿔 확인)
- [ ] 팀이 없는 새 계정으로 로그인하면 "팀 만들기 / 팀 찾기" 화면이 그대로 나옴
- [ ] 두 팀에 속한 계정은 팀을 바꾸면 그 팀의 홈이 보임 **[계정 2개]**

## 2. 홈 — 다음 경기 카드 (4-3, S4-02)
준비: 수요일 같은 정기 일정이 열려 있는 팀.
- [ ] 다음 경기 카드에 날짜·시간·내 상태(미투표/참석/불참/대기 N번)·참석 현황(예: 참석 9/12 · 대기 · 미투표)이 있음. "12"는 정원. 일정 상세의 숫자와 같음
- [ ] 카드에서 [참석] 또는 [불참]을 누르면 **일정 상세로 가지 않고** 바로 바뀜
- [ ] 카드의 글자 부분(버튼 말고)을 누르면 **일정 상세**로 감. 뒤로 가면 홈으로 돌아옴
- [ ] 진행 중인 경기(시작~종료 사이)는 "진행 중"으로 보이고, 다음 주 일정보다 먼저 나옴
- [ ] 다음 일정이 취소됐으면 그 일정은 건너뛰고 그 다음 일정이 나옴
- [ ] 참석 마감이 지난 경기는 카드에 [참석][불참] 버튼이 없음
- [ ] 일정이 하나도 없으면 "다가오는 경기가 없어요". [일정 추가] 버튼은 팀장·운영진에게만 보임
- [ ] 배치가 **초안**일 때 팀원 카드에는 팀 블록이 없음 (운영진도 홈 카드에는 확정된 것만)
- [ ] 배치를 **확정**하면 카드에 내 팀 블록이 크게 (조끼 색 배경, 이름 가나다순, 게스트는 "게스트" 상자). 실력·포지션 표시 없음. 다른 팀 이름은 카드에 안 나옴
- [ ] 교체 블록에 있는 사람은 교체 블록이 보이고, 배치에 없는 사람은 "이번 경기 배치에 없어요" + [전체 배치 보기] (누르면 일정 상세)
- [ ] 부상 중인 계정은 내 상태 자리에 "부상 중"

## 3. 홈 — 지난 경기 POM·오늘의 골과 카드 누르기 (4-4, kopn 지시)
준비: 경기가 끝나 투표가 열린 상태(묶음 테스트 03 10절처럼).
- [ ] 가장 최근에 끝난 경기에 투표가 열려 있으면 "투표 중 · 발표 {시각}"과, 투표 대상자에게만 [투표하기]
- [ ] 투표 대상이 아닌 팀원·이미 다 낸 사람에게는 [투표하기]가 없음
- [ ] [투표하기]나 카드를 누르면 그 경기의 POM·오늘의 골 화면으로 감
- [ ] 발표 뒤: 공동 1위면 모두 나오고, 아무도 안 찍은 항목은 "결과 없음". 득표수·순위는 어디에도 없음
- [ ] 1위가 그 뒤 팀을 떠났으면 이름 자리가 빈칸으로 나옴 (문구가 맞는지 메모)
- [ ] 가장 최근 경기에 투표가 안 열렸으면(참석자 2명 미만 등) 이 칸이 아예 없고, 그 전 경기 결과도 안 보임
- [ ] 홈에 있는 카드(다음 경기, 지난 경기 POM, 부상자, 처리할 일)는 **누르면 모두 해당 화면으로 바로 이동**하고, 뒤로 가면 홈으로 돌아옴. 이동 뒤 탭 바 상태도 이상 없음

## 4. 선호 포지션 — 올라운더 (1-8, kopn 지시)
- [ ] 내 정보(프로필 수정) 포지션 선택지가 골키퍼·수비·측면·공격·올라운더 (**"중앙" 없음**)
- [ ] 올라운더를 누르면 선택되고, 그 상태에서 다른 포지션을 누르면 선택이 안 되며 안내가 나옴
- [ ] 다른 포지션을 고른 상태에서 올라운더를 누르면 선택이 안 되고 안내. 고른 걸 빼면 올라운더를 고를 수 있음
- [ ] 올라운더 상태에서 "전문 골키퍼"를 체크하려 하면 막히고 안내
- [ ] 전문 골키퍼인 상태에서는 올라운더를 못 고름
- [ ] 기존에 "중앙"을 골랐던 계정의 프로필을 열어도 오류가 없음 (다른 포지션과 함께였으면 "중앙"만 빠지고, "중앙"만 있었으면 올라운더로 보임)
- [ ] 일정 상세에서 게스트를 추가할 때도 포지션 선택지가 같고 같은 규칙(올라운더 단독)
- [ ] 팀 나누기: 올라운더가 있는 팀(전원 올라운더인 작은 팀 포함)에서 [자동 나누기]가 오류 없이 되고, 올라운더는 골키퍼 나누기 규칙에 안 들어가며, 화면에 포지션이 안 보임

## 5. 부상 동의와 등록 (2-1~2-3)
준비: 부상 동의한 계정 B, 동의 안 한 계정 C.
- [ ] 내 정보 → "내 부상"에서 동의 안 한 C가 [부상 등록] → **동의 화면**(문구가 consent-texts 그대로). [동의하고 계속] 전에는 등록 화면이 안 나옴. 그냥 나가면 부상이 등록되지 않음
- [ ] C가 동의 → 바로 등록 화면. 예상 회복 기간을 1W~12W에서 고름(기본 2W), "12W보다 길면 12W로 등록 후 연장" 안내
- [ ] 메모는 선택. 20자까지 쓸 수 있고 21자를 넣으면 막힘. 이모지는 1개가 1자. 줄바꿈은 안 됨
- [ ] 이미 동의한 B는 동의 화면 없이 바로 등록 화면
- [ ] 등록하면 내 부상 카드에 "남은 회복 기간 NW", 예상 복귀일, 메모. 진행 중 부상이 있으면 [부상 등록] 버튼은 없음
- [ ] 남은 W 표시: 예상 복귀일이 7일 이내(1~7일) = 1W, 8~14일 = 2W. 등록 직후 N주로 등록했으면 NW로 보임 (지난 날짜로 직접 확인하긴 어려우니 2주·3주로 등록해 보기)
- [ ] 내 부상 카드의 [메모 수정]으로 메모를 고칠 수 있음 ("발목" → "발목 인대"), 예상 복귀일은 그대로
- [ ] [연장 +1W]·[연장 +2W]를 누르면 예상 복귀일이 늦춰지고 남은 W가 늘어남 (예상 복귀일 전이면 그 날짜부터 더하고, 이미 지났으면 오늘부터 더함)
- [ ] [회복했어요]를 누르면 내 부상 카드에서 부상이 사라지고 [부상 등록]이 다시 보임. **확인 창 없이 바로 처리되는 게 괜찮은지 메모** (임시)
- [ ] 회복하고 다시 [부상 등록]을 하면 새로 등록됨. 기간을 "줄이는" 기능은 없음(회복 후 다시 등록)이 맞는지 메모
- [ ] **이미 "참석"으로 응답한 일정이 있는 상태에서 부상 등록**: 등록 직후 "참석으로 되어 있는 경기가 있어요. 불참으로 바꿀까요?" + 경기 목록. [불참으로 바꾸기]를 누르면 불참으로 바뀜(대기 1번이 자동 참석되는지도 봄). [그대로 두기]면 응답이 그대로. 마감이 지난 경기는 "마감된 경기는 운영진에게 직접 알려주세요" **[실제 확인: 내 다가오는 참석 목록 listMyUpcomingAttending]**

## 6. 부상자 보기 — 홈·팀원 탭 (4-5, 6-1) [계정 2개]
준비: B가 부상 등록(메모 "발목", 3W). 다른 계정 A(팀원 또는 팀장)로 로그인.
- [ ] **[실제 확인]** A의 홈에 "부상자" 칸이 보이고 B의 이름·남은 W(3W)·메모가 나옴 (홈 부상자 목록이 실제 로그인에서 읽히는지)
- [ ] A의 팀원 탭에서 B 이름 옆에 작게 "부상 3W". 목록에는 메모가 없고, B를 눌러 프로필을 보면 메모가 있음
- [ ] 부상자 순서: 남은 기간이 짧은 사람 먼저, 같으면 이름 가나다순 (부상자 2명 이상일 때)
- [ ] 부상자가 아무도 없으면 홈에 이 칸이 아예 없음
- [ ] 홈 부상자 카드를 누르면 팀원 탭으로 감
- [ ] B가 [회복했어요]를 누르면 A의 홈·팀원 탭에서 사라짐 (당겨서 새로고침이 필요할 수 있음 — 얼마나 걸리는지 메모)
- [ ] B가 두 팀에 속해 있으면 두 팀 모두에서 B의 부상이 보임 **[계정 3개]**
- [ ] B가 부상 동의를 철회하면(8절) A 화면에서 즉시 사라짐
- [ ] 팀원 탭 맨 위에 "팀원 N명", 팀장 → 운영진 → 팀원 순(각각 가나다순). 목록에 선호 포지션·실력 등급이 없음 (관리자 계정으로 봐도)

## 7. 부상 중 참석과 복귀 확인 (1-5, 2-5, 1-6, 2-6) [계정 2개]
준비: B가 부상 중. 참석 마감 전 일정이 있음.
- [ ] 부상 중인 B가 일정 상세 [참석] → "부상에서 복귀하셨나요?" 확인 창. [복귀했어요] → 참석되고 부상이 해제됨 (내 부상 카드가 사라짐, 홈 부상자에서도 빠짐)
- [ ] 같은 창 [취소] → 응답도 부상도 그대로
- [ ] 홈 다음 경기 카드의 [참석]도 똑같이 확인 창이 뜸
- [ ] 부상 중 [불참]은 확인 창 없이 바뀌고 부상은 그대로
- [ ] 부상 없는 계정 C는 확인 창 없이 바로 참석
- [ ] 정원이 찬 일정(정원 3 등)에서 부상 중인 B가 [참석] → 확인 → "대기 N번"이 되고 부상은 해제됨. (취소하면 대기도 안 됨)
- [ ] **복귀 확인 알림(알림함)**: 부상 중인 B의 예상 복귀일 이후에 열리는 일정(경기 날짜가 예상 복귀일 이후)이 생성되면 B의 알림함에 "부상은 회복되셨나요? 경기가 열렸습니다. 참석하시겠습니까?"가 **팀 이름 제목으로 1번**. 같은 일정에 두 번 오지 않음. 경기 날짜가 예상 복귀일보다 앞이면 안 옴 (예: 1W로 등록 → 8일 이후 경기 일정을 직접 추가하면 감 / 오늘 경기면 안 감)
- [ ] 일정을 **직접 추가**해도 같은 알림이 부상자에게 감 (일정을 추가한 사람이 부상자 본인이어도 받음)
- [ ] 두 팀에 속한 B에게 팀 B 일정이 열리면 팀 B 이름으로 따로 감 **[계정 3개]**
- [ ] 회복하면 그 뒤 일정에는 복귀 확인 알림이 안 옴
- [ ] **[실제 확인] 푸시**: setup_push.ps1 재배포 뒤, 휴대폰에 푸시가 옴. 제목은 팀 이름, 내용은 위 문구. 새벽(00:00~08:00)에 일정이 열리면 알림함에는 바로, 푸시는 13:00에 옴 (일반 알림과 같음). 푸시 대기 중에 B가 먼저 회복했거나 그 일정에 응답했으면 푸시가 안 오고 알림함에만 남음
- [ ] 알림(푸시 또는 알림함)을 누르면 앱이 열리고 그 일정 상세 위에 작은 창: [참석할게요] [아직 회복 중 +1W] [+2W] [닫기]
- [ ] [참석할게요] → 참석 + 부상 해제. [아직 회복 중 +1W]/[+2W] → 예상 복귀일 늦춤, 응답 그대로. [닫기] → 그대로(다음 일정이 열릴 때 다시 알림)
- [ ] 참석 마감이 지난 일정의 알림을 누르면 [참석할게요] 대신 "마감됐어요"
- [ ] 이미 회복했거나 그 일정에 이미 응답한 뒤 알림을 누르면 창 없이 일정 상세만
- [ ] 알림이 가리키는 일정이 지워졌거나(10경기 정리) 팀을 떠난 뒤면 눌러도 이동하지 않음(오류 없이)
- [ ] 부상 중인 B에게는 미투표 알림이 안 옴(그 시각에 부상 중이면). 회복한 뒤 다음 일정에는 옴 — 미투표 알림 시각을 가깝게 설정해 확인
- [ ] (참여율) 마감 시각에 부상 중이던 B가 참석 응답 없이 경기가 시작되면 참여율 응답이 +1 → 내 기록 참여율에서 확인(10절). 부상이 아닌 미응답 계정은 +0

## 8. 부상 동의 철회 (2-4)
- [ ] 내 정보 설정에 "부상 정보 동의 철회"가 있음 — **동의한 계정에만**. 동의 안 한 C에게는 없음
- [ ] 누르면 확인 창("철회하면 부상 기록이 바로 삭제돼요"). [취소]면 그대로
- [ ] [철회] → 내 부상 카드·이력이 사라지고, 다른 계정(A)의 홈·팀원 탭에서도 즉시 사라짐 **[계정 2개]**
- [ ] 철회 뒤 [부상 등록]을 누르면 다시 동의 화면부터. 다시 동의해도 예전 부상 기록은 안 돌아옴
- [ ] 철회 메뉴의 위치·문구가 괜찮은지 메모 (임시)

## 9. 탈퇴·해체와 부상 (1-7)
- [ ] 부상 중인 B가 팀 A를 탈퇴하면 팀 A 홈·팀원 탭에서 B 부상이 사라지고 팀 B(다른 팀)에서는 그대로 **[계정 3개, 팀 2개]**
- [ ] 부상 중인 계정이 팀 탈퇴·팀장이 내보내기·팀 해체·회원 탈퇴를 해도 막히지 않음 (부상 기록이 있어서 오류가 나지 않음)
- [ ] 부상 중인 계정이 회원 탈퇴하면 가입할 때 동의 기록·부상 기록이 모두 사라짐 (같은 계정으로 다시 가입하면 부상 없는 새 계정)

## 10. 내 기록 (3-2, 3-3, S4-12) **[실제 확인: get_my_records]**
준비: 경기를 몇 번 치르고 POM·오늘의 골 투표가 끝난 팀. 계정 2개 팀 소속이면 더 좋음.
- [ ] 아래 탭 "내 기록" 맨 위에 시즌 버튼(누적 + 기록이 있는 연도만, 기본 누적)
- [ ] 그 아래 **전체 합산 카드**(POM 수상·오늘의 골 수상·출석 횟수·참석 투표 참여율)와 **팀별 카드**(지금 팀 먼저). 숫자가 실제 경기 결과와 맞음 (출석 횟수는 확정 배치에 들어 경기를 한 횟수)
- [ ] 시즌 버튼을 바꾸면 그 해 숫자만 보임. 그 해 기록이 없는 팀은 빠짐
- [ ] 참여율은 소수점 없이 반올림("75%", "67%"). 투표 대상이 0번이면 "0%"가 아니라 "기록 없음"
- [ ] **득표수는 어디에도 없음**, "득표수 보기" 버튼도 없음
- [ ] 팀을 떠난 뒤에도 그 팀 기록이 "(떠난 팀)"으로 남아 있음. 팀이 해체돼도 "(해체된 팀)"으로 남음 **[계정 2개]**
- [ ] 최근 10경기 정리로 오래된 경기가 사라져도 출석·수상 횟수는 줄지 않음 (정리가 일어난 팀이 있을 때만)
- [ ] 기록이 전혀 없는 새 계정은 안내 문구가 나오고 오류가 없음. 네트워크를 끄면 "다시 시도" 버튼
- [ ] 다른 사람 기록을 볼 방법이 없음 (팀원 프로필에도 없음)
- [ ] 그 아래 기존 항목이 그대로 동작: 프로필 보기·수정, 팀 식별코드, 팀 탈퇴, 로그아웃, 회원 탈퇴. **계정 연결 메뉴는 없음**

## 11. 일정 탭 — 목록과 달력 (5-1, 5-2, S4-13)
- [ ] 일정 탭 기본은 목록, "다가오는 경기 / 지난 경기" 두 칸 전환
- [ ] 한 줄에 "11/18(수) 10:00~12:00 · 장소 · 참석 N/정원 · 나: 상태". 정원이 없는 팀은 "참석 N"만. 대기 중이면 "나: 대기 N번"
- [ ] 취소된 일정은 "취소됨"이고 참석 숫자가 없음. 줄을 누르면 일정 상세
- [ ] 지난 경기는 최근 끝난 순으로 최근 10경기 + 그 사이 취소된 일정
- [ ] 목록 ↔ 달력 전환. 달력은 한국어(월·요일), 경기 있는 날에 점(취소된 일정은 회색 점), 처음엔 오늘이 선택돼 있음
- [ ] 날짜를 누르면 달력 아래에 그날의 경기가 나오고, 그 경기를 누르면 일정 상세
- [ ] 다음 달·지난 달로 넘기면 그 달 경기 점. 10경기 이전의 오래된 달은 비어 보임
- [ ] 일정 추가 버튼은 팀장·운영진에게만. 일정 추가·취소·상세 이동이 이전처럼 동작
- [ ] 어두운 모드에서도 달력이 읽힘
- [ ] 목록의 "나:"에 부상 중 표시가 없는데 괜찮은지 메모 (홈 카드는 "부상 중"으로 나옴)

## 12. 관리 탭과 처리할 일 (4-6, 6-2) [계정 2개]
준비: 팀장 A, 운영진 B(A가 B를 운영진으로), 팀원 C. 가입 신청을 한 번 더 넣을 계정이 있으면 좋음.
- [ ] 팀장·운영진 계정: 홈 위쪽에 "처리할 일" — 가입 신청 N건, 팀 나누기 대기(참석 마감 뒤·경기 종료 전·배치 미확정 일정). 팀원 C 화면에는 이 칸이 없음
- [ ] 가입 신청 줄을 누르면 관리 탭의 가입 신청으로, 팀 나누기 대기 줄을 누르면 **그 경기의 팀 배치 화면**으로 바로 감
- [ ] 관리 탭 아이콘에 가입 신청 수 숫자 배지. 신청을 승인·거절하면 배지·할 일이 사라짐(팀원 C 화면에는 숫자가 없음)
- [ ] 배치를 확정하면 "팀 나누기 대기" 줄이 사라짐. 할 일이 하나도 없으면 칸 자체가 없음
- [ ] 관리 탭: "팀장·운영진" 묶음(가입 신청 → 초대 코드 → 팀 설정[실력 등급·경기 설정·투표 설정·그룹·라이벌·팀 정보·모집]), "팀장만" 묶음(팀원 관리·해체). 운영진 B에게는 "팀장만" 묶음이 **통째로 안 보임**
- [ ] "출석·참여 리포트" 같은 메뉴가 어디에도 안 보임 (2차용 자리, 1차는 숨김)
- [ ] 팀장이 B를 운영진 해제하면, B가 앱을 다시 열었을 때 관리 탭이 없어짐

## 13. 그룹·라이벌 고르기 (6-4, kopn 지시)
준비: 팀원이 많을수록 좋음(10명 이상). 관리 탭 → 팀 설정 → 그룹·라이벌.
- [ ] 이름 검색 칸에 글자 일부만 쳐도 바로 걸러짐. 없는 이름이면 "없음" 안내. 영문 대소문자 구분 없음
- [ ] 목록은 가나다순이고, 고른 사람은 체크 표시 + 검색 칸 아래 **이름표**로 모임. 이름표의 X를 누르면 빠짐
- [ ] 검색어를 바꾸거나 지워도 이미 고른 사람은 이름표에 남아 있음
- [ ] 이미 만든 그룹·라이벌을 고치면 원래 고른 사람이 이름표·체크로 나옴 (팀을 떠난 사람은 안 나옴)
- [ ] 모순(그룹이면서 라이벌인 두 사람)이면 저장 버튼이 꺼지고 이유 안내
- [ ] 키보드가 올라와도 이름표·목록·저장 버튼이 가려지지 않음. 목록이 길어도 스크롤이 부드러움 (팀원 30명 이상이면 더 좋음)
- [ ] 저장 뒤 팀 나누기에서 그룹은 같은 팀, 라이벌은 다른 팀으로 나뉨 (묶음 테스트 03 2절 회귀)

## 14. 회귀 — 이전 기능이 그대로 (U-01, U-02)
