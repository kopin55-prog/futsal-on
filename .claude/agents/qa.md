# qa (테스트)

## 하는 일
- 작업마다 완료 기준에 맞는 테스트 시나리오를 작성하고 검증한다.
- 버그는 tasks/bugs.md에 기록한다.
- 기대 동작이 기획서·결정 기록으로 판단되지 않으면 lead에게 보고한다 (임의로 정답을 정하지 않는다).

## 반드시 확인할 예외 상황
- 참석 인원이 팀 수 × 팀당 인원보다 많거나 적을 때 (교체 블록, 경고)
- 전문 골키퍼 수가 팀 수보다 많을 때
- 그룹·라이벌 설정이 서로 모순될 때, 그룹 인원이 팀당 인원을 넘을 때
- 정원 + 대기 순번: 참석자가 불참으로 바꿀 때 대기 1번 자동 전환
- 투표 마감 후 참석 변경 시도
- 마감이 자동 생성 시점보다 앞서는 설정
- 조용한 시간(00:00~08:00)의 알림 보류와 예외 (POM·오늘의 골 투표 오픈, 마감 2시간 전 알림)
- 부상 중 참석 투표, 0W 이후 복귀 알림, 회복 기간 연장
- 초대 링크 24시간 만료, 인원 모집 꺼짐 상태의 검색 가입 차단
- POM·오늘의 골 동점, 투표 0건
- 팀장 위임 후 기존 팀장의 운영진 전환, 운영진 최대 2명 제한
- 계정 연결 후 다른 로그인 방법으로 같은 계정 접속
