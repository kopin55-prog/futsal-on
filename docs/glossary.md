# 용어집

| 용어 | 뜻 | 코드에서 |
| --- | --- | --- |
| 풋살ON | 앱 이름. 영문 표기 Futsal ON | futsal_on |
| POM | Player of the Match. 경기 후 투표로 뽑는 최우수 선수. 기획서의 "MVP"와 같은 뜻 | pom |
| 오늘의 골 | 경기 후 투표로 뽑는 그날 가장 멋진 골을 넣은 선수 | goal_of_the_day |
| 팀장 | 팀당 1명. 운영진 지정·해제, 팀원 내보내기, 위임, 해체 권한 | owner |
| 운영진 | 팀당 최대 2명. 가입 승인, 일정·배치 관리 | manager |
| 그룹 | 항상 같은 팀으로 배치할 사람들 | group_rule |
| 라이벌 | 항상 다른 팀으로 배치할 사람들 | rival_rule |
| 전문 골키퍼 | 본인이 체크하면 팀 나누기에서 골키퍼로만 배치 | is_dedicated_gk |
| 실력 등급 | 비기너·아마추어·세미프로·프로·미정. 팀장·운영진만 조회 | skill_level |
| 미정 | 실력 등급이 정해지지 않은 상태. 계산 시 아마추어로 간주 | undecided |
| 교체 블록 | 팀 배치 후 남은 인원이 표시되는 영역 | bench |
| 노조끼 | 조끼를 입지 않는 팀. 연한 회색으로 표시 | no_bib |
| 부상자 라인업 | 팀 대시보드에서 부상 중인 팀원을 보여주는 영역 | injury_list |
| W | 예상 회복 기간의 주 단위 표기 (4W = 4주) | weeks |
| 조용한 시간 | 알림을 보류하는 00:00~08:00 | quiet_hours |
| 매니저 말투 | 모든 알림에 쓰는 친근한 말투 | |
| 개인 구독 | 2차. 광고 제거 + 득표수 상세 | personal_plan |
| 팀 구독 | 2차. 운영진용 출석·참여 리포트 | team_plan |
| 팀 식별코드 | 팀마다 하나씩 붙는 고유 코드. 같은 이름 팀을 구분하고 가입코드로도 쓴다 (세부 Q-029) | team_code |
| 알림함 | 앱 안에서 지난 알림을 모아 보는 곳. 푸시와 함께 쌓인다 | notification_inbox |
