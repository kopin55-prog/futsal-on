# 묶음 테스트 03 (kopn 휴대폰 확인용) — 초안

작성 2026-11-09 builder (3단계 팀 나누기 화면, 5단계 투표·결과 화면 9~12절). 6·7단계(공유 이미지·보관 정리)는 해당 단계 구현 후 추가한다.
확인하면서 이상한 점·바꿀 문구를 아래 "메모"에 적거나 lead에게 말하면 된다. 화면 문구는 모두 임시(Q-067 0번).

## 실행 방법
1. 3단계 커밋 이후 새로 만든 설치 파일(APK) 또는 USB `flutter run`.
2. **계정 3개 이상**: 팀장 A, 운영진 B, 팀원 C (휴대폰 1대면 로그아웃·로그인으로 바꿔 가며). 배치가 의미 있으려면 참석자가 4명 이상이면 좋다(게스트로 채워도 됨).
3. 팀 나누기는 **참석 마감 뒤 ~ 경기 종료 전**에만 된다. 일정을 직접 추가할 때 마감을 0시간(시작 = 마감)으로 하거나, 시작이 가까운 일정을 만들어 마감이 지나게 한다.
4. 알림은 종 모양 → 알림함(푸시는 묶음 테스트 02의 setup_push 이후).

## 1. 버튼·시점 (3-1, Q-075 1번)
- [ ] 팀원 C의 일정 상세에는 "팀 배치" 부분에 "아직 팀 배치 전이에요"만 있고 "팀 나누기" 버튼이 없음
- [ ] 운영진 B·팀장 A에게는 "팀 배치" 오른쪽에 "팀 나누기" 버튼
- [ ] 참석 마감 전 일정: 버튼이 꺼져 있고 "참석 마감 뒤에 팀을 나눌 수 있어요"
- [ ] 취소된 일정: 버튼이 꺼져 있고 "취소된 일정은 팀을 나눌 수 없어요"
- [ ] 끝난 경기: 버튼이 꺼져 있고 "끝난 경기는 배치를 바꿀 수 없어요" (확정 배치가 있으면 보이기는 함). 일정 탭에 지난 경기가 아직 없으므로(5-1) 알림함의 배치 알림에서 들어가 확인

## 2. 팀 수·팀당 인원·자동 나누기 (3-1, Q-075 7번 (4))
- [ ] 처음 여는 팀(지난 배치 없음): 팀 수 2팀, 팀당 인원 = (참석자 + 게스트) ÷ 2 올림. 예) 참석 6 + 게스트 1 → 4명
- [ ] 한 번 배치를 저장한 뒤 **다른 일정**에서 열면 지난 배치의 팀 수·팀당 인원이 처음 값
- [ ] −/+ 로 팀 수 2~11, 팀당 인원 1~50 사이만 바뀜
- [ ] [자동 나누기] → 팀 블록이 조끼 색 배경(빨강, 파랑, 노랑 … 순서)으로 나오고, 블록 안 이름은 가나다순
- [ ] 게스트는 이름 뒤에 "게스트" 상자
- [ ] **실력 등급·점수·포지션·GK 표시가 어디에도 없음** (블록·경고·팀원 추가 목록 모두)
- [ ] 그룹(관리 탭)으로 묶은 두 사람은 같은 팀, 라이벌은 다른 팀, 전문 골키퍼 2명은 팀마다 1명씩 (재조합을 여러 번 눌러도)
- [ ] 팀당 인원을 줄여 사람이 남으면 교체 블록에 들어가고 "교체 N명, 직접 배치하세요" 경고. 남는 사람은 참석을 가장 늦게 누른 사람(게스트가 먼저), 전문 골키퍼는 마지막
- [ ] 팀당 인원을 늘려 모자라면 "N명 모자라요" 경고

## 3. 재조합·직접 옮기기 (3-2, Q-075 7번 (1)~(3))
- [ ] [재조합]을 누를 때마다 다른 배치 (같은 배치가 연달아 나오지 않음)
- [ ] 사람이 2~3명뿐인 일정에서 재조합을 계속 누르면 "모든 조합을 봤어요. 처음 배치로 돌아갔어요"
- [ ] 이름을 **길게 눌러 끌어** 다른 팀 블록·교체 블록에 놓으면 옮겨짐 (놓을 수 있는 블록은 테두리 강조)
- [ ] 이름을 **짧게 누르면** "○○ 옮기기" 목록(다른 팀으로 / 교체 블록으로 / 배치에서 빼기)
- [ ] 직접 옮긴 뒤 [재조합] → "직접 옮긴 내용이 사라져요" 확인 창. "그대로 두기"면 그대로, "다시 나누기"면 새 배치
- [ ] 라이벌 두 사람을 손으로 같은 팀에 넣어도 막지 않고 "라이벌이 같은 팀에 있어요" 경고. 그룹을 갈라 놓으면 "같은 팀이어야 할 그룹이 나뉘었어요", 전문 골키퍼 2명을 한 팀에 넣으면 "한 팀에 전문 골키퍼가 2명 이상 있어요"
- [ ] "배치에서 빼기"한 사람은 블록에서 사라지고, 교체 블록의 [팀원 추가]로 다시 넣을 수 있음

## 4. 팀원 추가 (Q-075 2번)
- [ ] 교체 블록의 [팀원 추가] → 배치에 없는 팀원 목록, 이름 옆에 대기/불참/미투표(빼낸 참석자는 "참석")
- [ ] 고르면 교체 블록에 들어감. 그 사람의 참석 응답은 바뀌지 않음(일정 상세 명단 그대로)
- [ ] 직접 넣은 사람은 [재조합]·[자동 나누기]를 눌러도 교체 블록에 그대로 남음 (계산은 참석자·게스트로만)

## 5. 조끼 색 (Q-075 8번)
- [ ] 팀 블록 오른쪽 팔레트 버튼 → 11가지 색 목록, 다른 팀이 쓰는 색은 흐리게 "다른 팀이 쓰는 색"이라 못 고름
- [ ] 노조끼를 고를 수 있음 (블록이 무늬 없는 회색 바탕 + 테두리)
- [ ] 같은 팀 수로 재조합해도 고른 색이 유지됨
- [ ] 어두운 모드에서도 블록 색이 조끼 색 그대로, 글자가 읽힘(흰색·노랑 블록은 검은 글자)

## 6. 저장·확정·변경 저장 (3-3, Q-075 7번 (5)(6)·9·10번)
- [ ] [초안 저장] → "초안을 저장했어요", 위에 "초안" + "초안은 팀원에게 보이지 않아요". 팀원 C 화면은 여전히 "아직 팀 배치 전이에요"
- [ ] 운영진의 일정 상세에도 "초안" 배치가 요약되어 보이고 버튼은 "배치 고치기"
- [ ] 교체 블록에 사람이 남은 채로 [확정] 가능 → 확인 창 → "배치를 확정했어요…"
- [ ] 확정 후 팀원 C: 일정 상세에 조끼 색 팀 블록·교체 블록, **내 이름이 진하게 강조**, 게스트 상자, 실력·포지션 없음
- [ ] 확정 알림: 배치 명단에 있는 팀원(교체 포함, 직접 추가한 사람 포함)의 알림함에 "팀 배치가 나왔어요", 확정한 운영진 본인·배치에 없는 사람은 없음
- [ ] 확정 뒤에는 [초안 저장]·[확정] 대신 [변경 저장] (고친 것이 없으면 꺼짐)
- [ ] 확정 뒤 3명을 차례로 옮기고 [변경 저장] 한 번 → 알림 **한 번**("배치가 바뀌었어요"), 빠진 사람도 받음
- [ ] 경기 시작 뒤(종료 전) 고치면 "경기가 시작돼서 변경 알림은 가지 않아요" 안내, 저장은 되고 알림 없음
- [ ] 고친 뒤 저장하지 않고 뒤로 가면 "저장하지 않은 변경이 있어요" 확인 창

## 7. 두 운영진이 동시에 (Q-075 7번 (5))
- [ ] 운영진 B와 팀장 A가 같은 배치를 동시에 열고, A가 먼저 [변경 저장] → B가 저장하면 "다른 운영진이 먼저 바꿨어요. 새로 불러올게요" → 확인 → A가 저장한 배치로 바뀜
- [ ] 배치 화면을 열어 둔 사이 대기자가 자동 참석하거나 게스트가 추가돼도(서버가 교체 블록에 자동으로 넣음) 저장 시 같은 안내 후 새로 불러옴

## 8. 강등·권한 (3-5)
- [ ] 운영진 B가 배치 화면을 열어 둔 채 팀장 A가 B를 운영진 해제 → B가 저장하면 거절 안내(화면 캐시와 무관)

## 9. 지난 경기 목록 (5-1, S3-16)
준비: 5단계 커밋 이후 새 설치 파일. 경기 종료 처리·투표 마감은 서버가 1분마다 자동으로 돈다.
- [ ] 일정 탭 "다가오는 일정" 아래에 "지난 경기": 끝난 경기가 최근 순으로, 취소된 일정은 줄 긋기 + "취소됨"
- [ ] 끝난 경기는 "다가오는 일정"에서 빠지고 "지난 경기"로 옮겨 감 (당겨서 새로고침)
- [ ] 취소 안 된 지난 경기가 10개를 넘으면 최근 10개만(그 사이 취소된 일정은 함께) 보임
- [ ] 지난 경기를 누르면 일정 상세 (1절 "끝난 경기" 확인도 여기서 가능)

## 10. POM·오늘의 골 투표 (5-2, Q-075 13번)
준비: 참석(또는 확정 배치) 2명 이상인 경기가 끝나면 1~2분 안에 투표가 열린다. 마감 = 경기 다음날 투표 설정 시각(기본 15:00).
- [ ] 투표가 열리면 대상자에게 "수고하셨어요! ..." 알림, 누르면 그 경기 상세
- [ ] 대상자 C의 상세 "POM·오늘의 골": "투표 마감 {날짜 시각}", POM·오늘의 골이 따로 있음
- [ ] 후보: 대상자 중 본인 빼고 이름 가나다순. 게스트 없음. 경기 뒤 팀을 떠난 사람 없음
- [ ] 이름을 고르기 전에는 [투표하기]가 꺼져 있음. 고르고 누르면 확인 창("…님에게 투표할까요? 투표한 뒤에는 바꿀 수 없어요.") → [취소]면 그대로, [투표]면 "투표했어요" + 그 항목 "투표 완료"
- [ ] "투표 완료" 뒤에는 누구를 찍었는지 보이지 않고 바꿀 수 없음. 앱을 껐다 켜도 "투표 완료" 그대로
- [ ] POM만 내고 오늘의 골은 나중에 낼 수 있음. 같은 사람을 두 항목에 찍을 수 있음
- [ ] 몇 명이 투표했는지·득표수는 어디에도 안 보임
- [ ] 대상자가 아닌 팀원(그날 참석 안 함·나중에 들어온 사람)은 투표 버튼 없이 "이번 경기 투표 대상이 아니에요"
- [ ] 대상자가 1명뿐이던 경기·끝나지 않은 경기·취소된 경기는 "POM·오늘의 골" 부분 자체가 없음
- [ ] 마감 시각이 막 지났을 때(1분 이내) 열어 두었던 화면에서 투표하면 "투표가 마감됐어요."

## 11. 결과 (5-3, S3-12)
준비: 투표 설정 발표 시각을 확인하기 편한 시각으로 바꾼 뒤 경기를 끝내면 그 다음날 그 시각에 마감된다(바꾼 시각은 다음에 열리는 투표부터).
- [ ] 발표 시각에 대상자에게 "오늘의 POM·오늘의 골 결과가 나왔어요!" 알림, 누르면 그 경기 상세 (발표 시각이 00~08시면 지금은 알림함에 바로, 휴대폰 푸시는 13:00. Q-077 1번 답에 따라 바뀔 수 있음)
- [ ] 팀원 전체(대상자가 아니어도)에게 항목별 1위 이름. 공동 1위면 모두. 득표수·순위 없음
- [ ] 아무도 안 찍은 항목은 "결과 없음"
- [ ] 1위가 그 뒤 팀을 떠났으면 빠지지 않고 이름 자리에 "(팀을 떠난 사람)"으로 보임 (배치 화면과 같은 표시, Q-058 5번). 모두 떠났어도 "결과 없음"이 아님
- [ ] "득표수 보기" 버튼 없음 (1차 숨김)

## 12. 알림 이동·배치 미확정 알림 (5단계)
- [ ] 배치 확정·배치 변경·배치 미확정·투표 시작·결과 발표 알림을 누르면 모두 그 경기 상세로
- [ ] 경기 시작 때 배치가 미확정이면 팀장·운영진에게 "…팀 배치가 아직 확정 전이에요" 알림, 누르면 그 경기 상세. (푸시 직전에 배치가 이미 확정돼 있으면 푸시를 건너뛰는 규칙은 notifier 재배포 후 적용. 그 틈이 짧아 휴대폰으로는 확인이 어렵고 서버 테스트로 확인함)
