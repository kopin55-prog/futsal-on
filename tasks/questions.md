## 형식
```
### Q-000 [대기|답변 완료] 질문 제목
- 배경:
- 선택지: A) … / B) … / C) …
- lead 추천: (있으면, 이유와 함께)
- 막힌 작업:
- 답변: (kopn 답변 후 기록)
```
