# 알림

## 규칙
- 모든 알림은 친근한 매니저 말투. 예: "이번 주도 뛰어야죠! 참석하실 거죠?"
- 조용한 시간 00:00~08:00: 알림을 보류했다가 08:00에 모아서 발송
- 예외 1: 경기 종료 직후 POM·오늘의 골 투표 오픈 알림은 조용한 시간에도 바로 발송
- 예외 2: 마감 2시간 전 알림이 조용한 시간에 걸리면 00:00 전에 미리 발송

## 목록
| 알림 | 받는 사람 |
| --- | --- |
| 일정 생성·참석 투표 오픈 | 팀원 전체 |
| 참석 투표 마감 2시간 전 | 미투표자 (부상자 제외) |
| 대기 → 참석 자동 전환 | 본인 |
| 일정 취소 | 투표자 전원 |
| 팀 배치 확정, 확정 후 변경 | 참석자 |
| POM·오늘의 골 투표 오픈 | 참석자 |
| POM·오늘의 골 마감 2시간 전 | 미투표 참석자 |
| 가입 신청 도착 | 팀장·운영진 |
| 가입 승인·거절 | 신청자 |
| 팀원 탈퇴 | 팀장·운영진 |
| 팀 해체 | 팀원 전원 |
| 부상 복귀 확인 (0W 이후 투표 오픈 시) | 본인 |
| 월말 요약 리포트 (2차, 팀 구독) | 팀장·운영진 |

## 문구
알림별 실제 문구는 아직 정하지 않았다. builder가 초안을 쓰면 lead를 통해 kopn 승인을 받는다.
확정 문구: 부상 복귀 알림 "부상은 회복되셨나요? 경기가 열렸습니다. 참석하시겠습니까?"

## 추가 결정 (2026-11-04)
- 모든 알림은 앱 안 알림함에도 쌓인다 (Q-027). 조용한 시간에 생긴 알림을 알림함에 바로 쌓을지는 Q-033 대기
- 추가 알림 (Q-022): 운영진 지정·해제 → 본인 / 팀장 위임 받음 → 본인 / 내보내기 당함 → 본인
- 부상 복귀 알림 등 부상 관련 동의 절차는 없음 (Q-003, Q-028 확인 대기)
