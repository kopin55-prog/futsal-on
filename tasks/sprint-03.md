- **경기 종료 처리 하나에 묶는 것**(11장 18번): 출석 기록 + 시즌 출석 카운트 + 월간 출석 수 + 팀별 월간 경기 수 + `closed_out_at` + POM 투표 회차 열기(대상자 복사·득표 0줄)를 한 처리 안에서. 배치 미확정 경기는 팀별 월간 경기 수만 +1(R-18). 02 기간에 끝난 경기도 첫 실행 때 소급 처리된다(배치가 없으므로 경기 수만 +1).
- **투표 마감 처리 하나에 묶는 것**: 1위 줄 + 수상 카운트 + `award_polls.status=closed`, 직후 최근 10경기 정리 실행(7-5).

- **새 알림 종류는 데이터 구조(9장 알림 종류 목록) 변경**: 배치 미확정 알림(S3-15), 결과 발표 알림(S3-14 (3))은 답이 "넣는다"여도 재승인 전에는 만들지 않는다.

## QA 완료 기준
qa는 아래 문장을 시나리오로 만든다. 시각은 모두 한국 시간, 서버 시계 기준. 준비: 팀 A(팀장 A0, 운영진 A1·A2, 팀원 A3~A14), 팀 B(팀장 B0). 예약 작업은 수동 실행 수단으로 시각을 당겨 확인. BLOCKED 항목(S3-xx)은 답이 나온 뒤 기대 결과를 채운다.

### 팀 나누기 알고리즘 (자동 테스트 + 시나리오)
- K-01 12명, 2팀 × 6명 → 6:6, 교체 0명, 경고 없음
- K-02 전문 GK 2명, 2팀 → 팀마다 1명씩. 재조합을 10번 눌러도 매번 지켜짐
- K-03 그룹(A3·A4) 켜짐 → 항상 같은 팀. 그룹을 끄면 갈라질 수 있음
- K-04 라이벌(A5·A6) 켜짐 → 항상 다른 팀
- K-05 그룹·라이벌·GK를 모두 지킬 수 없는 입력 → 배치는 나오고 해당 경고 표시
- K-06 실력: 프로 2·비기너 2, 2팀 × 2명 → 팀마다 프로 1·비기너 1 (S3-05 점수 기준)
- K-07 미정 4명 + 아마추어 4명, 2팀 × 4명 → 팀마다 미정 2명
- K-08 선호 포지션 공격 4명, 2팀 → 팀마다 공격 2명(다른 조건이 같을 때)
- K-09 일반 선호 포지션이 골키퍼인 사람은 GK 분산(1번 규칙)에 들어가지 않음
- K-10 15명, 2팀 × 7명 → 교체 블록 1명 + "교체 1명, 직접 배치하세요" 경고 (누가 가는지 S3-04)
- K-11 10명, 2팀 × 6명 → 5:5 + "2명 모자라요" 경고
- K-12 게스트(이름 없음 "게스트1", 대략 실력·포지션 있음)도 계산에 들어감. 게스트는 그룹·라이벌·전문 GK 대상 아님
- K-13 재조합 → 매번 다른 배치(같은 배치가 연달아 안 나옴)
- K-14 실력 등급·점수는 결과·화면·이미지 어디에도 안 나옴

### 경기 종료 처리
